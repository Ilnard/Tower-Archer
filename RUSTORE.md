# Публикация «Башенного лучника» в RuStore

Регистрация и публикация в RuStore бесплатные. Физлицо входит через VK ID. Проверку документов RuStore запрашивает только для своей монетизации (платежи и подписки внутри приложения), а она нам не нужна: доход от рекламы платит Рекламная сеть Яндекса напрямую.

## Что загружать

| Поле | Значение |
|---|---|
| Файл | **`TowerArcher-1.0.N.apk`** — релизный APK из GitHub Releases (сейчас `TowerArcher-1.0.14.apk`). Не `test`-сборку и не `.aab`. |
| Подпись | Ваш ключ из `release-key`. Все следующие версии должны быть подписаны **этим же ключом** — CI делает это автоматически. |
| Пакет | `com.ilnard.towerarcher` |
| Минимальная версия Android | 7.0 (определяется из файла автоматически) |

## Шаги

### 1. Аккаунт разработчика (≈10 минут)
1. Откройте [console.rustore.ru](https://console.rustore.ru), войдите через VK ID.
2. Тип аккаунта — **физическое лицо**. Заполните данные. Если консоль потребует статус самозанятого или ИП, напишите мне: подскажу, как его оформить.
3. Контакты разработчика: почта **towerarcher042@gmail.com**, сайт **https://ilnard.github.io/Tower-Archer/**.

### 2. Создание приложения
1. «Приложения» → «Добавить приложение» → загрузите `TowerArcher-1.0.14.apk`.
2. Заполните карточку по таблицам ниже.
3. Загрузите иконку и скриншоты из `C:\Dev\TowerArcher\store`.
4. Заполните раздел безопасности данных.
5. В комментарии для модератора вставьте текст из раздела «Комментарий для модератора».
6. Отправьте на модерацию.

### 3. После публикации
- Пришлите ссылку на игру в RuStore. Её стоит добавить в настройки приложения в Рекламной сети Яндекса: «Реклама в приложениях» → Tower Archer → ссылка на магазин. Это повышает доход от рекламы.
- Обновления: я собираю новую версию, вы загружаете новый APK в RuStore и пишете, что нового. Номер версии растёт автоматически.

## Безопасность данных

- **Собирает ли приложение данные:** да, через SDK рекламы Яндекса.
- **Категории данных:**
  - **Идентификаторы устройства** (рекламный идентификатор): цель — реклама. Передаются Яндексу по шифрованному каналу. Персонализацию можно отключить в игре: «Настройки» → «Персонализированная реклама».
  - Всё остальное — местоположение, контакты, файлы, фото, сообщения, финансы, история — **не собирается**.
- **Разрешения:**
  - интернет и состояние сети — для загрузки рекламы;
  - вибрация — для отклика в игре;
  - рекламный идентификатор — для рекламы.
  - Чувствительных разрешений (камера, микрофон, контакты, местоположение, файлы) **нет**.
- **Политика конфиденциальности:** https://ilnard.github.io/Tower-Archer/privacy.html
- **Согласие игрока:** при первом запуске игрок сам выбирает кнопкой, разрешать ли персонализированную рекламу. До выбора SDK рекламы не запускается.

## Комментарий для модератора

> Игра полностью нативная для пользователя и работает офлайн: весь код игры (HTML5 Canvas, JavaScript) встроен в APK в папку assets и загружается локально. Приложение не открывает внешний сайт и не является обёрткой веб-страницы. Интернет нужен только для необязательной рекламы с вознаграждением (Yandex Mobile Ads SDK), которую игрок запускает сам кнопкой после поражения — чтобы продолжить бой или удвоить монеты. Во время боя реклама не показывается. Учётной записи нет, прогресс хранится на устройстве.

## Если модерация отклонит

- **«Приложение на основе WebView»:** ответьте модератору текстом из комментария выше. Если отказ останется, следующий шаг — перенос игры на движок (Godot), как предлагал исходный план. Это несколько дней работы, не часов.
- **Другая причина:** пришлите текст отказа, исправлю и соберу новую версию.
