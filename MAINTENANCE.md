# Обслуживание «Башенного лучника»

Памятка для обновлений и исправлений. Новая сессия с Claude начинается без памяти о прошлых — эта страница даёт всё, чтобы продолжить с того же места.

## Где что лежит
- **Код:** GitHub `Ilnard/Tower-Archer` (публичный), ветка `main`. Единственный источник правды.
- **Игра целиком:** `app/src/main/assets/index.html` (HTML5 Canvas + JS). Веб-копия `docs/play/` собирается `python3 tools/build_web.py`.
- **Android-обёртка:** `app/src/main/java/com/ilnard/towerarcher/` — `MainActivity` (WebView), `GameBridge` (JS ↔ Android), `AdsManager` (реклама Яндекса).
- **Сборка:** каждый push в `main` → GitHub Actions → раздел **Releases**: `TowerArcher-1.0.N.apk` (для RuStore), `.aab` (для Google Play в будущем), `TowerArcher-test-1.0.N.apk` (тест).
- **Ключ подписи:** `C:\Dev\TowerArcher\release-key` + 4 секрета в GitHub. Все версии подписываются только им.
- **Реклама:** Рекламная сеть Яндекса, приложение 20373346, блок с вознаграждением `R-M-20373346-1` (задан в `app/build.gradle`).
- **Магазин:** RuStore, консоль `console.rustore.ru`, пакет `com.ilnard.towerarcher`. Инструкция — `RUSTORE.md`.
- **Сайт и политика:** https://ilnard.github.io/Tower-Archer/ (папка `docs/`), почта `towerarcher042@gmail.com`.
- **Баланс:** `tools/economy_model.py`, `tools/balance_bot.js`. **Графика магазина:** `tools/store_shots.js`, `tools/store_compose.js`, `tools/render_icon.js` (собираются в релиз `store-assets`).

## Как выпустить обновление
1. Опишите Claude, что нужно: новая функция, баланс, исправление. Для ошибки — по шаблону ниже.
2. Claude вносит правки, проверяет в браузере и при необходимости ботом, отправляет в GitHub. Номер версии растёт автоматически (1.0.N, код 1000+N).
3. Проверьте `TowerArcher-test-1.0.N.apk` на телефоне (ставится рядом с основной игрой, демо-реклама, есть панель тестировщика).
4. Загрузите `TowerArcher-1.0.N.apk` в RuStore: «Версии» → «Загрузить версию», заполните «Что нового».
5. Если менялся облик игры — обновите скриншоты (релиз `store-assets`, папка `promo`).

**Нельзя:** менять пакет `com.ilnard.towerarcher`, терять ключ подписи, загружать в RuStore test-сборку.

## Шаблон сообщения об ошибке

- Как повторить: волна, облик башни, что нажимали.

- Скриншот или запись экрана. Если отзыв из RuStore — текст отзыва.

## Перед каждым обновлением (быстрая проверка)
- [ ] Первый запуск: согласие → обучение → меню.
- [ ] Бой, пауза, сворачивание, кнопка «Назад».
- [ ] Поражение: повтор, откат на волну назад, реклама за награду (в тесте — демо).
- [ ] Перезапуск приложения: волна, монеты, улучшения на месте.
- [ ] Обновление поверх прошлой версии сохраняет прогресс.

## Известные риски
- **Модерация RuStore** может придраться к WebView. Ответ: игра встроена в APK и работает офлайн. Запасной путь — перенос на Godot (несколько дней).
- **Реклама** в первые дни после публикации показывается редко — блоку нужно время.
- **Сканер RuStore** видит «AdMob»: это библиотека рекламного ID от Google внутри SDK Яндекса, AdMob не подключён.
- **Android 17+** на планшетах: игра помечена как игра (`appCategory="game"`), поэтому остаётся в портретной ориентации.
- **Требования магазинов** меняются (целевой API Android, правила данных). Раз в полгода — сверка.
