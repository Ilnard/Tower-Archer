# Релиз «Башенного лучника» в Google Play

## Как устроена сборка

- **Единственный источник игры** — `app/src/main/assets/index.html`. Веб-версия (`docs/play/`) и предпросмотр собираются из него скриптом `python3 tools/build_web.py`. В CI шаг `--check` не даёт собрать APK, если копии разошлись.
- Каждый push в `main` запускает GitHub Actions. Файлы появляются в разделе **Releases**:
  - `TowerArcher-test-1.0.N.apk` — тестовая версия. Это отдельное приложение «Лучник (тест)», пакет `com.ilnard.towerarcher.dev`. В нём демо-реклама Яндекса, панель тестировщика и отладка WebView. Ставится рядом с релизной версией.
  - `TowerArcher-1.0.N.aab` — файл для Google Play Console, подписан ключом загрузки.
  - `TowerArcher-1.0.N.apk` — та же релизная сборка в виде APK, чтобы проверить её на телефоне.
  - Релизные файлы собираются, только когда в секретах GitHub есть ключ загрузки.
- **Отличия релиза от тестовой версии:**
  - подпись ключом загрузки, а не тестовым ключом;
  - отладка WebView выключена;
  - панели тестировщика нет;
  - рекламный блок берётся из переменной `YANDEX_REWARDED_ID`; пока её нет — подставляется демо-блок.
- `targetSdk` и `compileSdk` равны 36: это требование Google Play для новых приложений с 31 августа 2026 года.
- Шрифты Russo One и Nunito (лицензия OFL) встраиваются в APK при сборке. Игра работает без интернета, к Google Fonts не обращается.
- Реклама — Yandex Mobile Ads SDK 7.18.7, формат «с вознаграждением»:
  - SDK запускается только после того, как игрок выбрал, разрешать ли персонализацию;
  - награда выдаётся только по событию `onRewarded`;
  - если реклама не загрузилась, повторные попытки идут через 5 с, 10 с и так далее, но не реже чем раз в 2 минуты.

## Что сделать владельцу

### 1. GitHub: 4 секрета ключа загрузки и Pages (≈5 минут)
1. **Settings → Secrets and variables → Actions → New repository secret.** Добавить:
   - `UPLOAD_KEYSTORE_B64` — всё содержимое файла `UPLOAD_KEYSTORE_B64.txt`;
   - `UPLOAD_KEYSTORE_PASSWORD` — пароль из `upload-key-ПАРОЛЬ.txt`;
   - `UPLOAD_KEY_PASSWORD` — тот же пароль;
   - `UPLOAD_KEY_ALIAS` — `upload`.
2. **Settings → General → Danger Zone → Change visibility → Public.**
3. **Settings → Pages → Source: Deploy from a branch → Branch `main`, папка `/docs` → Save.** Через 1–2 минуты политика конфиденциальности откроется по адресу https://ilnard.github.io/Tower-Archer/privacy.html.
4. Сохранить `upload-keystore.jks` и пароль в менеджере паролей и сделать резервную копию.

### 2. Почта для связи
Указать адрес, на который игроки и Google смогут писать по вопросам конфиденциальности. Он заменит `CONTACT_EMAIL` в `docs/privacy.html` и понадобится в карточке приложения.

### 3. Рекламная сеть Яндекса (≈20 минут)
1. Зарегистрироваться в партнёрском интерфейсе Рекламной сети Яндекса: [partner.yandex.ru](https://partner.yandex.ru), раздел мобильных приложений.
2. Добавить приложение: Android, пакет `com.ilnard.towerarcher`. Ссылку на Google Play можно добавить позже.
3. Создать рекламный блок типа **«С вознаграждением» (Rewarded)**. Получится ID вида `R-M-1234567-1`.
4. Записать ID в **Settings → Secrets and variables → Actions → Variables → New variable**: имя `YANDEX_REWARDED_ID`, значение — ID блока. Либо прислать ID разработчику.
5. Заполнить платёжные данные для выплат.

### 4. Google Play Console
1. Аккаунт разработчика: разовый взнос $25 и проверка личности.
2. **Создать приложение:** «Башенный лучник: Защита башни», язык по умолчанию — русский, тип — игра, бесплатное.
3. **Подписание:** включить Play App Signing (по умолчанию) и загрузить первый `.aab`. Ключ загрузки определится автоматически.
4. **Закрытое тестирование — обязательно для новых личных аккаунтов:** не меньше **12 тестировщиков**, которые не выходят из теста **14 дней подряд**. Только после этого можно запросить доступ к рабочей версии. Тестировщиков удобно собрать в Google Группу.
5. Заполнить разделы из пункта «Ответы для Play Console» ниже и загрузить графику из релиза `store-assets`.

### 5. Проверка на телефоне
Пройти чек-лист в конце этого файла на тестовой и на релизной сборке.

## Карточка приложения

**Название (29/30):** Башенный лучник: Защита башни

**Краткое описание (77/80):** Защищай башню одним пальцем: бесконечные волны, боссы и улучшения без предела

**Полное описание:**

> Враги наступают из леса — и только твой лучник на башне стоит у них на пути!
>
> Веди пальцем к цели и отпускай тетиву. Иногда лук выпускает веер из пяти стрел, а огненные, ледяные и взрывные наконечники превращают каждый выстрел в маленькую бурю.
>
> • Бесконечные волны: каждая сильнее предыдущей, а 17 видов врагов умеют лечить, уклоняться, призывать подмогу и прятаться в тени.
> • Пять боссов каждые 20 волн. Ночью, при свете факелов, на башню идут Вождь гоблинов, Каменный колосс, Королева теней, огненный дракон Игнис и Король-лич. У каждого свои умения — следи за подсказками и бей вовремя.
> • Улучшения без предела: урон, скорость стрельбы, залп, огонь, пробитие, тип стрел и «Добыча».
> • Навыки: метеоритный дождь, быстрая перезарядка и ледяная буря.
> • Четыре облика башни открываются по мере продвижения: деревянная застава, лесной форт, каменная цитадель и королевский бастион.
> • Не получается пройти волну? Вернись на шаг назад, накопи монет и попробуй снова.
> • Музыка и звуки, которые сочиняются прямо во время игры.
> • Играй без интернета: прогресс хранится на устройстве. Реклама — только по твоему желанию, за награду.

## Ответы для Play Console

**Политика конфиденциальности:** https://ilnard.github.io/Tower-Archer/privacy.html

**Реклама:** «Да, приложение содержит рекламу».

**Доступ к приложению:** «Все функции доступны без особого доступа».

**Целевая аудитория:** 13–15, 16–17, 18+. Не выбирать возраст младше 13 лет: тогда приложение попадёт в программу «Для всей семьи», а у неё отдельные требования к рекламным SDK.

**Возрастной рейтинг (анкета IARC):**
- категория — игра;
- насилие: фэнтезийное или мультяшное, против вымышленных существ, без крови;
- страх, сексуальный контент, ненормативная лексика, наркотики, азартные игры — нет;
- общение пользователей и обмен данными — нет;
- покупки в приложении — нет;
- местоположение — нет.

Ожидаемый рейтинг — 7+.

**Безопасность данных (Data safety)** — по документации Яндекса для SDK 7:
- **Собирает ли приложение данные?** Да.
- **Передаются ли данные третьим лицам?** Да: Яндексу, через SDK, для рекламы.
- **Шифруются ли данные при передаче?** Да.
- **Может ли пользователь запросить удаление?** Разработчик данные не хранит. Персонализацию можно отключить в настройках игры, рекламный ID — сбросить в настройках Android.
- **Типы данных:**
  - «Идентификаторы устройства или другие идентификаторы»: собираются и передаются; цель — реклама и маркетинг; сбор необязателен (пользователь может отказаться от персонализации).
  - Местоположение, личная информация, финансы, сообщения, фото, файлы, контакты, история в приложении, история браузера — **не собираются**.

**Новости / COVID / госорганы / финансы / здоровье:** не относится.

## Чек-лист проверки на телефоне

**P0 — до загрузки в закрытый тест**
- [ ] Первый запуск: согласие на рекламу → обучение из 4 шагов → меню. Выбор согласия запоминается.
- [ ] Бой, пауза кнопкой, сворачивание и возврат: игра на паузе, звук не играет в фоне.
- [ ] Кнопка «Назад»: пауза → продолжение. В меню — выход из игры.
- [ ] Поражение:
  - «Начать заново»;
  - «Вернуться на волну назад» (включается повтор, кнопка «Вперёд»);
  - «Продолжить за рекламу»: награда выдаётся только после досмотра; если закрыть рекламу раньше, награды нет и появляется сообщение;
  - «Удвоить монеты»;
  - без интернета — сообщение «Реклама недоступна», игра не зависает.
- [ ] Закрыть приложение из списка недавних посреди волны → открыть снова: та же волна, монеты и улучшения на месте.
- [ ] Поставить новую сборку поверх старой: прогресс сохранился.
- [ ] Релизная сборка: в настройках нет панели тестировщика. В тестовой сборке панель есть.
- [ ] Ссылка «Конфиденциальность» открывается в браузере.

**P1 — до публичного запуска**
- [ ] Маленький экран, вырез камеры, планшет: видны HUD, кнопки навыков, карточки и Лагерь.
- [ ] Два пальца на экране, прерванный свайп (звонок, шторка): прицел не залипает.
- [ ] Волны 1–50: темп, хватает ли монет, первый босс на 20-й волне сложный, но проходимый.
- [ ] Сброс прогресса (в тестовой сборке) и повторное прохождение обучения из настроек.
- [ ] Минимальная версия Android 7.0 (если есть устройство) и актуальная версия WebView.
